# Postman API Collection

## Giới thiệu
Thư mục chứa bộ Postman Collection để kiểm thử các API của hệ thống đặt sân cầu lông.

## Hướng dẫn sử dụng
1. Mở Postman.
2. Nhấn **Import** và chọn file [badminton-court-booking.postman_collection.json](file:///Users/vanhuy/Desktop/NhanNguyen/Semeter_7/badminton-court-performance-evaluation/testing/Postman/badminton-court-booking.postman_collection.json).
3. Đảm bảo biến `baseUrl` trỏ tới `http://localhost:5001`.
4. Chạy request **Health Check** để kiểm tra kết nối tới server.
