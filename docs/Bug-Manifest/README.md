# Bug Manifest (Bảng theo dõi và quản lý lỗi)

## Bảng theo dõi lỗi dự án (Bug Tracking Matrix)

| Bug ID | Tóm tắt lỗi (Summary) | Mức độ (Severity) | Trạng thái (Status) | Người phát hiện | Người sửa | Ghi chú |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| BUG-000 | Baseline placeholder | Low | Closed | QA Team | Dev Team | Hệ thống khởi tạo baseline |

### Quy chuẩn mức độ lỗi (Severity):
- **Critical**: Lỗi nghiêm trọng ảnh hưởng trực tiếp đến hệ thống (sập server, mất dữ liệu, thanh toán sai).
- **Major**: Tính năng chính bị lỗi không thể tiếp tục thực hiện luồng nghiệp vụ.
- **Moderate**: Tính năng phụ bị lỗi hoặc luồng có giải pháp thay thế.
- **Minor**: Lỗi giao diện nhỏ, chính tả, màu sắc.
